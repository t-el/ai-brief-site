## Top stories

### 1. GPT-6 designs proteins that bind in the lab

**What happened.** On November 24, OpenAI published results showing its GPT-6 family can generate new protein backbones and sequences using only reasoning and general-purpose code, without calling specialized biology models to produce the designs. With research partner Onava, a pre-release GPT-6.2 designed minibinders for five targets (including PD-L1 and VEGF-A); 35 of 322 tested (10.9%) showed binding, and redesigned antibodies kept binding.

**Why it matters.** It is another sign that one general model can stand in for a chain of specialist tools at some steps of scientific work. But read the caveats OpenAI itself gives: specialized models (Boltz-2, ESMFold2, SolubleMPNN) still filtered candidates and supplied sequences, full structure prediction remains well behind specialist models, and binding is only the first step toward a drug. OpenAI also flags the dual-use risk directly.

**Sources:** [OpenAI](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/) · [SEN-X Daily Briefing](https://senx.ai/news/2026-11-25-daily-ai-news)

### 2. Anthropic: Skills over MCP, plus Tasks and Elicitation go GA

**What happened.** For MCP's second anniversary, Anthropic launched *Skills over MCP* in public beta in Claude and Claude Code: an MCP server can now publish playbooks alongside its tools, and Claude loads them only when needed. *Tasks* (servers run long jobs or full agent loops in the background) and *Elicitation* (a server pauses to ask the user to confirm via a form or link) are now GA on Pro, Max and Ultra plans, rolling out to Team and Enterprise. File Uploads is "coming soon." Early users include Shopify, HubSpot, Atlassian, Supabase and GitHub.

**Why it matters.** MCP is moving from "a way to call tools" toward "a way for agents to delegate to other agents." Elicitation is the practical safety piece: Supabase confirms costs before creating a paid project and GitHub makes users type a repo's name before an agent deletes it. If you build integrations, shipping a skill with your server is now a cheap way to make agents use your product correctly.

**Sources:** [Claude by Anthropic](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more) · [The New Stack](https://thenewstack.io/mcp-skills-tasks-claude/) · [The Next Web](https://thenextweb.com/news/anthropic-claude-skills-over-mcp-tasks-elicitation)

### 3. Google will require agents to reach Workspace data through MCP

**What happened.** Google made its Workspace MCP servers (Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat, Tasks; Keep coming) and an official Workspace CLI generally available. It also introduced Standard (free, published quotas) and Scaled usage tiers, with Scaled billing for usage above free allowances from April 1, 2027. The key policy: AI agents must use the MCP servers or CLI rather than Workspace REST APIs directly, with technical enforcement starting **February 1, 2027**.

**Why it matters.** This is the biggest platform-level endorsement of MCP so far, and it has a deadline. Anyone running agents or automations (including n8n/Zapier-style AI agents) against Gmail or Drive through raw REST calls should plan a migration. Google says over 99% of developers stay within the free Standard tier.

**Sources:** [Google Workspace Updates](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html) · [AI Compass](https://ashutoshai.com/ai-compass/2026/11/24/)

### 4. US blacklists Megaspeed and six affiliates over AI-chip diversion

**What happened.** The Commerce Department's Bureau of Industry and Security added seven entities to the Entity List, effective November 23 and published November 25: Megaspeed International (Singapore), PT Megaspeed International, Speedmatrix and MSFusion (Malaysia), Megaspeed (Thailand), Swiftdata, and Apex Enterprise Solutions (Singapore), which Reuters reports is an Alibaba subsidiary. The rule cites "significant risk" of diverting advanced computing commodities; all exports now need a license under a presumption of denial. Alibaba says Apex never diverted restricted chips.

**Why it matters.** The listing lands amid the Nvidia leadership scandal tied to Megaspeed. For companies renting GPU capacity in Southeast Asia, it is a supply-chain issue: check whether any cloud or reseller in your stack touches the listed names. Expect more export-control scrutiny of regional GPU resellers.

**Sources:** [Federal Register](https://www.federalregister.gov/documents/2026/11/25/2026-23999/additions-to-the-entity-list) · [Reuters via Investing.com](https://www.investing.com/news/stock-market-news/us-to-blacklist-alibaba-subsidiary-and-megaspeed-linked-to-nvidia-scandal-5046337) · [The Verge](https://www.theverge.com/policy/1041270/nvidia-megaspeed-commerce-dept-entity-list) · [Semafor](https://www.semafor.com/article/11/23/2026/commerce-to-add-megaspeed-to-trade-blacklist)

### 5. XPENG unveils its Turing Physical AI architecture and IRON robot

**What happened.** At its eighth AI Day on November 25, XPENG presented the Turing Physical AI Architecture (VLA 3.0), a single framework linking AI cognition, real-time decision-making and physical control across its cars and humanoid robots, built on its own chips, models and hardware. It also showed the IRON humanoid robot.

**Why it matters.** Chinese automakers are betting that the same vision-language-action stack can drive both vehicles and robots, spreading the cost of chips and models across product lines. It is a vertical-integration play that mirrors Tesla's Optimus strategy.

## Deep dive: MCP just became the default plumbing for AI agents

Two announcements on the same day, from two competitors, point the same way.

**From optional protocol to required interface.** Anthropic launched MCP two years ago as an open standard for connecting agents to data. This week Google, which controls one of the biggest pools of business data, said agents *must* use MCP (or its CLI) to reach Gmail, Drive and Calendar from February 2027. When a platform makes a protocol mandatory, it stops being a developer preference and becomes infrastructure.

**What changes for builders.**

1. *Tools are no longer enough.* With Skills over MCP, a server ships its own instructions, so the agent learns *how* to use your product, not just *what* it can call. Skills update with the server, so there is nothing for users to install.
2. *Long jobs fit the model.* Tasks let a server run for minutes or hours (for example, investigating a failing CI run) while the agent keeps working, which suits real back-office work better than single tool calls.
3. *Human sign-off is built in.* Elicitation gives a standard way to pause for confirmation before spending money or deleting data, which is what enterprises need before they let agents act.
4. *Quotas and billing arrive.* Google's tiers show platforms will meter agent traffic separately from human API traffic. Free for most today, but agent-heavy products should budget for the Scaled tier.

**The catch.** Centralizing agent access through vendor-hosted MCP servers also centralizes control: Google decides which tools exist, how results are summarized, and what admins can block. Developers trade flexibility for lower integration cost and easier security reviews.

**What to do now.** If you sell automations or SaaS integrations, (a) audit anything that calls Google Workspace REST APIs on behalf of an AI agent and plan the move before Feb 1, 2027; (b) consider publishing an MCP server with a skill for your own product; and (c) design destructive actions around an explicit confirmation step, because that is quickly becoming the expected pattern.
